# 1 · Tablón

**Dirección:** el tablón de anuncios del colegio electoral.

**La idea:** el día de las elecciones lo primero que miras son las listas pegadas en la puerta del
colegio. Vota con Criterio se publica igual: hojas impresas sujetas con cinta sobre corcho, tablas
que se consultan con el dedo y una tira perforada para «arrancar» el test.

**Tipografías:** Archivo (Google Fonts), una sola familia usada en su eje de anchura: condensada
y negra en mayúsculas para titulares y cifras, ancho normal para el texto y los controles.

**Paleta:**

| Rol | Hex |
|---|---|
| Corcho (fondo) | `#a9814f`, con grano generado en SVG |
| Papel de las hojas | `#fbfaf7` |
| Papel de notas | `#f1efe9` |
| Tinta | `#161513` |
| Tinta secundaria | `#4a4741` |
| Filete suave | `#d3cfc6` |
| Pista de barras | `#e7e4dd` |

El color solo aparece en la muestra cuadrada y la barra de cada partido.

**Por qué encaja:** es un objeto cívico y neutro que todo votante ha visto, sin ningún color
asociable a un partido (corcho y papel). El formulario de casillas «marque con una X» hace que el
cuestionario se lea como un trámite y no como un test de revista, y el resultado se publica como
un aviso con su fuente al pie de cada hoja: el dato manda.

**Señas:** tira perforada con tijera para empezar; casillas cuadradas con una X dibujada; sello
«Provisional»; cada hoja lleva su pie de referencia (hoja, fuente).
